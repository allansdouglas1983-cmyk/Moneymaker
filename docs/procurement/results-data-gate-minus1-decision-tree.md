# Gate −1 decision tree — F2+ results data (updated 2026-07-18, zero-cost-first)

Founder strategy: zero-cost routes are exhausted before any paid provider. Gate −1
(SPEC-101: licensed data before live; here applied to MODEL TRAINING data) is evaluated
per source; a model depending on data that cannot lawfully continue to be used has not
passed a gate. Research informs; it never proves a gate. Every branch outcome is
recorded; silence is never permission.

```
START: F2 global Elo needs (a) an OUTCOME source, (b) later families need ENRICHMENT.

(a) OUTCOME SOURCE
│
├─ 1. Betfair BASIC May-2026 sufficiency pilot (£0 expected)
│   ├─ portal price ≠ £0 ............................ STOP, report, re-plan (no purchase)
│   ├─ price £0 → pilot checks 1–8 (runbook)
│   │   ├─ PASS → propose BASIC backfill 2021-01→2026-05
│   │   │         (earlier only if the outcome-blind cold-start audit shows need)
│   │   │         → Gate −1 evaluation for "Betfair BASIC as F2 outcome source":
│   │   │           DR-0001 licence assessment + unresolved written clarifications
│   │   │           (cloud/CI wording, personal automated betting, retention)
│   │   │           ├─ rights adequate → GATE −1 PASS (outcome source) → F2 unblocked
│   │   │           │    scope: global Elo, outcome-only BT, recency/workload ONLY
│   │   │           └─ rights gap → written Betfair clarification; if refused → branch 2
│   │   └─ FAIL (structural: no terminal statuses, id instability, gaps)
│   │        → report measured failure → branch 2
│   └─ (June lockbox never opened in any branch; May/backfill = pre-June scope)

│   ├─ SportsDataAPI (free/$19.99) — written answers to the 8 questions

└─ 3. All routes fail → fundamental programme stays blocked (recorded honestly).

│

│        → branch 2
├─ 2. Paid fallbacks (same two providers, enrichment fields) — founder approval first
└─ 3. No enrichment source → F3/F5/F6 remain blocked; F2/outcome-BT proceed on (a) alone.

STANDING: Sackmann/Tennis Abstract & scraping-derived sources — PROHIBITED in the
deployable path (rights); SPEC-100 quarantine applies to any research-side use.
Goalserve/enterprise feeds — DEFERRED on cost. June lockbox — sealed in every branch.
```
