## Root cause (defect, not data corruption)

The driver's `read_outcomes` reads every bundle market and propagates a per-market
`OutcomeUndeterminedError` as a TOTAL failure. A frozen pre-outcome universe can legitimately
contain markets that later settle void — the platform's own rule is that such markets must become
**explicit exclusions with a reason, never a crash** ("the universe is frozen before outcomes are
known; missing data produces an explicit exclusion"). `score_bundle` already models exclusions;
the driver's read loop does not. The synthetic dry-runs all settled cleanly, so this path was
first exercised on real data. The stream files themselves are intact and readable; nothing about
the underlying data is corrupted.
